= Database secrets
:experimental:

A database secret authenticates tools and agents to a graph database attached to a Savanna workspace.
Use one when you configure TigerGraph MCP or other clients that talk to the data plane.

== Create a database secret

. Open *Database Secrets* in Savanna.
. Create a secret, then select the workspace, database, and graph if prompted.
. Copy the secret and store it securely. You will not be able to view it again after you leave the page.

[CAUTION]
====
Treat database secrets like passwords. Do not commit them to source control.
====

For secrets in Admin Portal or GraphStudio, see https://www.tigergraph.com/docs/gui/4.3/admin-portal/management/user-management/#manage-secrets[Manage secrets^] and https://www.tigergraph.com/docs/tigergraph-server/4.3/user-access/user-credentials/#_create_a_secret[Create a secret^].
